# DieFotoApp

Die einfache Foto-App 

* Import vom iPhone
* Personen- und Objekterkennung mit automatischer Albenerstellung
* Dia-Show
* Foto-Editor u.A. 
  * Zuschnitt, Begradigung,
  * Kontrast, Helligkeit, Schatten, Lichter, Schärfe)
  * Bild-Format ändern
  * Auflösung ändern
  * Objekte aus Bild entfernen (KI)
  * Bild kann mit KI editiert werden
* Alben erstellen
* Fotos können in der Gesamtsicht und den Alben frei angeordnet werden
* KI-Bilder erzeugen mit KI-Modell von BlackForrest Lab
* Geheimtexte in Fotos verstecken und Auslesen
* Einfaches Backup aller Fotos
* Backup Deiner iPhone-Fotos
* Automatische Update-Funktion
* Update aller verwendeten Software-Libraries
